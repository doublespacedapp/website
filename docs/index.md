A gradebook for teachers of any grade, from kindergarten through twelfth.
It runs as a real program on Windows and macOS, and as an app you install from this page on a Chromebook.
It works with no internet connection, and every score stays in a file that belongs to you.

[Install it](./install.html) or [open the web app](./app/) and try it now.
Choose **Try a sample class** on the first screen and you can look around a full class without typing anything.

## Filling it in

Grades are a grid of students down the side and assignments across the top, and you fill it in from the keyboard without reaching for the mouse.
Arrow keys move between cells, typing enters a score, and Enter moves down to the next student, so a stack of papers goes in as fast as you can read them.

Single letters do the rest.
Type `m` for missing work and `x` to excuse it, and add `l` after a score for late: `8l` is an eight handed in late.
Whether late work is docked, and by how much, is yours to decide.

Subjects and standards colour and filter that grid, so you can look at one standard across the whole class without building a separate view for it.
Colour follows performance rather than decoration, so where a class is struggling is visible before you have read a single number.

## Bringing a class in

You do not have to type your roster.
Students can be pasted in as a list, and if you use Google Classroom, its "Download all grades as CSV" file brings your class list, your assignments and your marks in together.

The import shows you what it would do before it does any of it, and asks which version to keep when a mark in the file disagrees with one you have already entered.
It never deletes anything, and importing the same file again updates what is there rather than making a second copy of it.

Standards do not have to be typed either.
Common Core Math, Common Core English Language Arts and the Next Generation Science Standards are built in, and a set can be narrowed to the grade you teach on the way in.

## Report cards

Report cards give you a page for each student, for each grading period.

It shows the course grade the assignments add up to, and beside it, where the student stands on each standard.
Those are different questions and the page keeps them apart on purpose: an average is not the same as knowing whether a student can do something.

Then there is the grade you decide to give, which is yours and is not calculated, and room for comments.
A comment you write often can be kept and used again.

Report cards print, with ruled lines for a signature and a date.
Finalising one fixes what it says, so a grade you have already sent home does not quietly change when you enter a late assignment afterwards.

## Seeing it over time

Trends draws what you have already entered across the length of the year, for one student or for the class together, from grades, from benchmark tests, or from behaviour records.

For one student it shows whether they are climbing or sliding, standard by standard.
For the class it shows the same thing as an average, so you can see whether a unit landed.
Every chart has a table underneath it if you would rather read the numbers.

## What it does not do

There is no account to make and no server to sign in to.
Nothing about your students is sent anywhere, because there is nowhere for it to be sent.

The one exception is Google Drive backup, which you turn on yourself if you want it, and which puts a copy in *your* Drive and nowhere else.
It is the one part of the app that costs money, at <!--price--> once, and [its own page](./drive.html) explains exactly what it can and cannot see.
Everything else is free, and is meant to stay that way.

There is no save button either.
Every edit is written down as you make it.
