Your gradebook is on your computer, and it stays there.
There is no server behind this app, so there is nowhere else for it to be.

Read this one in September, while you still have time.

## There is no save button

Every edit is recorded the moment you make it, then written into your file a second later.

That order matters.
If your file is open in another program, on a drive you have unplugged, or on a disk that is full, your work is already safe on the computer and the file catches up as soon as it can.
The app will tell you when that happens.

## Where the copies are

Settings, under Sync, lists every copy, says where each one is, and lets you move it.

**In the app**, on this computer.
This one always exists.

**A file of your own.**
On Windows and macOS this is switched on from the first time you open the app, in your Documents folder.
On a Chromebook you pick the file yourself.

**Google Drive**, which is optional and the one part that costs money, at <!--price--> once.
[It has its own page](./drive.html).

These are the same gradebook, not different ones, and the app keeps them level without asking you which is real.
It asks only when the same gradebook was changed in two places at once.

Rename your gradebook in Settings and every copy is renamed with it.

## Backups

Dated backups are written the first time you open the app each day and again as you leave, never more than hourly.

Say where they go under Saved Backup Location.
Your school drive is a good answer: a backup is the only copy that survives losing the device.

Restoring is in the same place — a dated backup from the list, or a file you saved yourself.
It replaces everything in the current gradebook, and asks first.

## Carrying a class somewhere else

Save a class as a template from Setup, then Class, and open it somewhere else.
That is how you carry a course into next year, or hand it to a colleague.

## What differs by computer

On Windows and macOS all of this works without your thinking about it.

On a Chromebook, Chrome may ask once when you come back whether the app may still write to your file.
If that file is in Google Drive, turn on Available offline so you can mark without Wi-Fi.

Firefox and Safari cannot hand a web app a file to write to at all, since their makers have never built it.
Your gradebook would live inside the browser on that one computer, and you would have to save every backup by hand.
Take the desktop installer instead.

## Erasing it

Settings has Start over, which erases the gradebook on this computer.
It asks first, and says plainly that a backup file is the only way back.
